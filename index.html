Settings

The app uses Twelve Data REST data for latest US prices, 5-minute intraday candles, and previous daily candles for multi-day trade planning. Automatic refresh is quota-aware and may slow down when several US stocks are visible. A temporary API failure keeps the last successful live price instead of switching the card to fallback. Extended-hours requests require compatible data access; manual override remains available. Alpha Vantage news is optional. API keys are stored separately from exported portfolio backups.
