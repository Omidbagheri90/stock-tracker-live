Settings

The app uses Twelve Data REST data for latest US prices and on-demand chart analysis. The analyzer combines 5-minute, 1-hour, derived 4-hour, and daily structure; Ichimoku confirmation; VWAP; opening range; approximate 5-day Volume Profile (VAL/POC/VAH); volume; support/resistance; and optional Alpha Vantage news. For owned positions that recover to break-even, the analyzer switches into profit-protection mode and follows momentum with a dynamic trailing profit floor instead of forcing an early fixed sale. For 1-second US price updates, the app uses a continuously connected Alpaca WebSocket and redraws the latest market price every second; Twelve Data remains the chart-analysis source. Free Alpaca uses IEX; paid SIP can be selected for consolidated US-exchange pricing. The analyzer now uses one 5-minute history request and derives H1/H4/daily structure locally to avoid rate-limit errors. API keys are stored separately from exported portfolio backups.
